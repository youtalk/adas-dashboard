# Recordings

One directory per run, one JSONL file per endpoint, one message per line, the first line a `hello`. Play them with `python3 -m tools.replay stack=<dir>/stack.jsonl:8090 world=<dir>/world.jsonl:8091`, and add `supervisor=<dir>/supervisor.jsonl:8092` if the run has that file. To see the end of a run, do not add `--loop`. The files have different lengths, so a loop drifts them apart.

The times count from the first message after the `hello` of each file, because `replay.py` starts each file there. On the bench, VisionPilot sent its first frame about 6 s after the recorder connected, and the other two endpoints sent theirs at once. The files have no common clock, so a replay cannot line them up. A replay of the bench run therefore shows Stack lost for about 6 s before the takeover. On the bench the first Safety Island command came 0.64 s after the kill.

The generated run stays. Only it plays through all six states of design section 6.3, and the replay smoke test (`src/replay.test.ts`) and CI depend on it. Recordings are CC0.

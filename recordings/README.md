# Recordings

One directory per run, one JSONL file per endpoint, one message per line, the first line a `hello`. Play them with `python3 -m tools.replay stack=<dir>/stack.jsonl:8090 world=<dir>/world.jsonl:8091`. To see the end of a run, do not add `--loop`. The two files have different lengths, so a loop drifts them apart.
